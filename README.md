*2 Player Hangman Game*
    This is a simple 2-player hangman game written in C. Player 1 enters a secret word, and Player 2 tries to guess
    the word one letter at a time. 

*FEATURES*
- 2-player gameplay
- player name input
- secret word input
- hidden word displayed using underscores
- letter guessing
- correctly guessed letters are revealed
- keeps track of guessed letters
- continues until the entire word is guessed

*HOW IT WORKS*
- Both players enter their names
- Player 1 enters the secret word
- The screen is cleared to hide the word from Player 2
- Player 2 guesses letters one at a time
- Correctly guessed letters are revealed
- The game continues until the entire word is guessed

*WHAT I PRACTICED*
- variables and data types
- character arrays and strings
- for loops
- while loops
- if statements
- user input with scanf
- Arrays

*Future Improvements*
In the future, I hope to add the option to continue playing so that player2 has the chance to 
input a secret word and Player 1 can guess. I also plan to add error prevention with if statements
so that the users can't enter more than one letter or a character/number.
